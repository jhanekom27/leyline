## Description

Some improvements make leyline nicer to use but nothing else depends on them: limits that surprise a user, rough edges a feature left behind once it shipped, small gaps between features that each work on their own. They tend to be neither urgent nor large, so they get lost behind feature work or built in a hurry. This umbrella is where they are tracked until someone has a quiet hour for them.

Tickets here stand alone and are picked up when convenient, not on any critical path. Each should say what surprised a user (the trigger), not only what to change, so it can be weighed against the effort when it comes up.
